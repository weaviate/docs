`wcloud` is a command-line interface for [Weaviate Cloud (WCD)](/go/console?utm_content=cloud). You can use it from a terminal, and AI coding agents can use it too.

`wcloud` creates, lists, and inspects clusters, and lists regions. It does not touch data in a cluster. For that, use a [client library](/weaviate/client-libraries). It cannot delete a cluster, change a plan, or manage billing, users, or organizations. Use the [Weaviate Cloud console](https://console.weaviate.cloud/) for those.

AI coding agents do not need a separate integration. An agent learns `wcloud` by running [`wcloud guide` or `wcloud skill install`](#use-wcloud-from-an-ai-coding-agent).

## Install the wcloud CLI

<Tabs groupId="wcloud-install">
<TabItem value="brew" label="Homebrew (recommended)">

```bash
brew install weaviate/tap/weaviate-cloud
```

Homebrew is recommended on macOS and Linux. It needs no Go toolchain.

</TabItem>
<TabItem value="npm" label="npm">

```bash
npm install -g weaviate-cloud
```

npm wraps the same binary. Use it on Windows (x64).

</TabItem>
<TabItem value="go" label="Go">

```bash
go install github.com/weaviate/weaviate-cloud/cmd/wcloud@latest
```

Go builds from source. For the minimum Go version, see the [wcloud README](https://github.com/weaviate/weaviate-cloud#install).

</TabItem>
</Tabs>

Check the installation:

```bash
wcloud version
```

For the details of each install channel, see the README's [Install section](https://github.com/weaviate/weaviate-cloud#install).

## Sign in

```bash
wcloud auth login
wcloud auth whoami
wcloud auth logout
```

Browser OAuth is the only way to sign in, so **`wcloud` cannot sign in on a headless machine**. There is no API key flag, token flag, or environment variable. The browser must run on the same machine as `wcloud`.

Once signed in, `wcloud` refreshes the credential itself. For the sign-in timeout, the listener ports, and the credential file locations, see the README's [Authentication section](https://github.com/weaviate/weaviate-cloud#authentication).

## Create a free cluster

```bash
wcloud cluster create --name my-cluster --wait
```

`--name` is optional. `--wait` blocks until the cluster is `READY`. Otherwise, poll `wcloud cluster status`.

The result includes the cluster's REST and gRPC endpoints and a **one-time API key**. The key is shown once, either by a `--wait` create when the cluster becomes `READY` or by the first `wcloud cluster get` after it is ready. `wcloud` never stores it, and every later call returns the key field empty, so save it when you see it. To add, rotate, or delete cluster API keys afterwards, see [Authentication](/cloud/manage-clusters/authentication).

By default, `wcloud` creates a `free` cluster in `eu-central-1`, currently the only region. `--tier` accepts only `free`. For a paid [Shared Cloud](/cloud/manage-clusters/create#shared-cloud-clusters) cluster or advanced settings, use the console as in [Create a cluster](/cloud/manage-clusters/create). For every flag, see the README's [Commands section](https://github.com/weaviate/weaviate-cloud#commands).

Inspect clusters and regions:

```bash
wcloud cluster list
wcloud cluster get <cluster-id>
wcloud cluster status <cluster-id>
wcloud region list
```

Once a cluster is `READY`, [connect a client library to it](/weaviate/connections/connect-cloud).

## Limits and boundaries

### There is no delete command

Delete a cluster in the [Weaviate Cloud console](https://console.weaviate.cloud/). Pick it with the `CLUSTER` selector in the left sidebar, then delete it from its `Dashboard`.

### One free cluster per account

Each account gets one free cluster at a time, across every organization. A suspended cluster still uses the slot. `wcloud cluster list` shows only the current organization, so it may not show the cluster that uses your slot. The [console](https://console.weaviate.cloud/) shows all organizations. To free the slot, delete the cluster there or [upgrade to a paid plan](https://weaviate.io/pricing). [Free clusters](/cloud/manage-clusters/create#free-clusters) explains when a free cluster is suspended or deleted. For current limits, see [Free tier allowance](/cloud/manage-clusters/create#free-tier-allowance).

When the slot is taken, `wcloud cluster create` fails with the error code `quota_exceeded`. Retrying does not help. For every error code and exit code, see the README's [Exit codes section](https://github.com/weaviate/weaviate-cloud#exit-codes).

## Use wcloud from an AI coding agent

```bash
wcloud guide
```

`wcloud guide` prints agent-facing Markdown that is always current with the installed binary. It ignores `--output`.

Once the cluster is ready, the guide tells the agent what to offer next. First comes [`weaviate/agent-skills`](https://github.com/weaviate/agent-skills), which works in the same session. Next is the cluster's [MCP server](/weaviate/configuration/mcp-server#weaviate-cloud), which most harnesses only load after a restart. The [client libraries](/weaviate/client-libraries) are the fallback.

```bash
wcloud skill install --all
```

This writes the guide as a `SKILL.md` where each supported harness reads it. `--harness` picks harnesses, and `--project` writes to the current project instead of your user directory. For the supported harnesses and the install options, see the README's [coding agent section](https://github.com/weaviate/weaviate-cloud#using-wcloud-with-a-coding-agent).

Cluster creation requests include an `X-Provisioned-By` header whose value is one word, `cli` or `agent`, and it is sent only to the Weaviate Cloud API.

## Machine-readable output

Commands that return a result write a JSON envelope (`data` or `error`, plus `metadata`) to standard output. `-o json` forces it. The default `auto` picks JSON when stdout is not a terminal or `CI` is set. Exit codes are part of the contract. For the envelope, the `auto` rules, and the exit-code table, see the README's [Status](https://github.com/weaviate/weaviate-cloud#status), [Commands](https://github.com/weaviate/weaviate-cloud#commands), and [Exit codes](https://github.com/weaviate/weaviate-cloud#exit-codes) sections.
