- A **[web interface](#select-a-cluster)** in the Weaviate Cloud console.
- An **[API endpoint](#api-endpoint)** that provides information about your Weaviate instance.

## Cluster status information

You can see the following cluster statistics at the top of the page:

- `Object count`
- `Endpoint health check`

You can find the following information on the cluster `Dashboard`:

- `Name of the cluster`
- `REST Endpoint`
- `gRPC Endpoint`
- `API Keys`
- `Roles`
- `Weaviate Database version`
- `Cloud provider`
- `Cloud region`
- `Created at`
- `Product` (for example, `Free`)
- `Deployment` (for example, `Shared`)
- `Backup retention days` (only for Shared Cloud cluster)
- `Availability SLA` (only for Shared Cloud cluster)

`Product` is the plan you pay for and `Deployment` is the infrastructure the cluster runs on. They are separate: a `Free` cluster runs on a `Shared` deployment, so `Deployment: Shared` on its own does not mean you are being billed.

Clusters also have an `Advanced configuration` section to configure or check the status of these additional settings:

- `Enable auto schema generation`
- `Allow all CORS origins`
- `Enable MCP Read-Only` (see [Weaviate MCP server](/weaviate/configuration/mcp-server#weaviate-cloud). The MCP server itself is always enabled, and changes apply without a restart)
