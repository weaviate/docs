:::info Compression defaults depend on deployment

**Weaviate Cloud:** The cluster's [optimization profile](/cloud/manage-clusters/create#optimization-profile) sets defaults for new collections. `Cost Optimized` uses HFresh with automatic compression; `Performance Optimized` uses HNSW with [RQ](/weaviate/configuration/compression/rq-compression). The free tier enforces `Cost Optimized`. On paid Shared clusters, you can choose a profile and explicitly configure each collection's index and compression. See [Cloud default settings](/cloud/manage-clusters/default-settings).

**Self-managed:** Starting with `v1.33`, [`DEFAULT_QUANTIZATION`](/deploy/configuration/env-vars#DEFAULT_QUANTIZATION) can set quantization for new collections when the collection definition does not specify it. The variable is unset by default, so it does not select a quantization method. HFresh has mandatory built-in RQ compression independently of this variable.

Changing a default does not reconfigure existing collections. Once enabled on a collection, quantization can't be disabled. The selected method must be supported by the index type; for example, PQ and SQ are not supported for flat indexes.

:::
