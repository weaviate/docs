:::info Compression by Default

For self-managed Weaviate, [`DEFAULT_QUANTIZATION`](/deploy/configuration/env-vars/#DEFAULT_QUANTIZATION) sets a default for **new** supported vector indexes (available from `v1.33`). It is unset by default in core configuration; ordinary HNSW/flat indexes then receive no default quantizer unless configured explicitly. HFresh is different: its required built-in RQ compression applies independently of this unset default.

Defaults apply only where the index/quantizer combination is supported and no explicit collection setting takes precedence. They do not recompress existing collections. Quantization enabled on a collection cannot be disabled in place.

Weaviate Cloud defaults depend on the [optimization profile](/cloud/manage-clusters/create/#optimization-profile): Cost Optimized uses HFresh with built-in compression, while Performance Optimized uses HNSW with RQ. See [Cloud default settings](/cloud/manage-clusters/default-settings/) for current policy and free-tier enforcement; do not infer one default or override policy for every Cloud cluster.

:::
