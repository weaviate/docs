:::info Dynamic index requires `ASYNC_INDEXING`
Dynamic indexes require asynchronous indexing. For self-hosted Weaviate, opt in by setting the [`ASYNC_INDEXING` environment variable](/deploy/configuration/env-vars/#ASYNC_INDEXING) to `true`. On Weaviate Cloud, asynchronous indexing is enabled by default and is not user-configurable. See [Cloud default settings](/cloud/manage-clusters/default-settings/#weaviate-database-settings).
:::
